# Creating an AMI from an EC2 Instance

## Objective

Create an Amazon Machine Image (AMI) from an EC2
instance and use the AMI to launch a new EC2 instance.

## AWS Services

- Amazon EC2
- Amazon AMI
- Amazon EBS
- Security Groups

## Architecture

EC2 Instance
    ↓
Create AMI
    ↓
MyEC2Image
    ↓
New EC2 Instance

## What I Learned

- What an AMI is
- How to create an AMI from an EC2 instance
- How to launch an EC2 instance from a custom AMI
- How AMIs help standardize EC2 deployments
- Difference between AMI and EBS Snapshot
